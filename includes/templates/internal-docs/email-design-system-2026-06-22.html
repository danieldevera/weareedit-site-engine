Email Design System — biblioteca de componentes

Fonte única para emails Brevo da EDIT. · v1 · 2026-06-22

Catálogo dos blocos reutilizáveis dos nossos emails: fundações (tokens, tipografia, grelha, regras mobile) e cada componente com a sua função, variáveis a trocar, estado (bloqueado ou aberto) e o ficheiro-fonte canónico para copiar. Objetivo: todos os emails montam-se a partir destes blocos, sem reinventar layout.

01Componentes

Shell / container Aberto

Wrapper exterior (#f5f5f5) + container 680px branco. Abre e fecha cada email; todas as secções são tabelas-filhas de 680px.

Fonte: qualquer template (ex.: _welcome-email-locked.html linhas 35–42)

Header Aberto

Logo EDIT. (160px) à esquerda + data de edição {{ISSUE_DATE}} ou label à direita.

Trocar: label direito (ex.: "Novo Bootcamp", data).

Fonte: _welcome-email-locked.html (header)

Hero — texto Aberto

Eyebrow (cor de formato) + H1 com acento pink + lede. Para lançamentos com criativo, usar a variante imagem (abaixo).

Trocar: eyebrow, H1 (palavra/frase em highlight), lede.

Hero — imagem Aberto

Criativo quadrado/retangular do produto (ex.: o creative AAI), largura total do container, linkado à página com UTMs. Usar quando há arte dedicada.

Trocar: src da imagem (alojar no Brevo ou WP media), alt, URL+UTM.

Signature card (Founder) Bloqueado

Foto 84px circular + assinatura cortada 180w + label FOUNDER. Liga ao perfil do fundador. Usado em cartas/editoriais.

Fonte: _welcome-email-locked.html (signature card) · spec: locked_founder_signature_card

Banda DGERT (prova de autoridade) Bloqueado

Banda preta (#0a0a0a) com badge DGERT branco + "Entidade Formadora Certificada · DGERT nº 18391". Existe versão grande (84px, hero) e compacta (44px, dentro da secção de vendas).

Fonte: grande → _welcome-email-locked.html; compacta → _sales-section-default.html

Section heading Aberto

H2 grande (30–34px) com ponto/dois-pontos em pink. Ex.: "Em destaque agora:" / "As próximas edições."

Trocar: texto do título.

Course card (pick) Canónico

Cartão de produto em linha: imagem 280×280 (foto do tutor ou criativo) + texto, alternando esquerda/direita entre cartões. Eyebrow + título + 1 linha + tutor + "Ver programa ›". Cor segue o formato (pink/teal/blue). Colapsa em mobile via .row-table.

02Montagem (ordem típica)

Newsletter / email de produto monta-se nesta ordem:

  • Shell (abre) → Header
  • Hero (texto ou imagem) → lede → CTA principal
  • (editorial) Signature card + Banda DGERT
  • Section heading ("Em destaque agora:") → [SALES-SECTION-AUTO-START]
  • Course cards ×N (cor por formato, foto alternada) → [SALES-SECTION-AUTO-END]
  • Promo banner (se campanha ativa)
  • Footer (white) → Shell (fecha)

03Regras

  • Cor de formato sempre: bootcamp pink, workshop teal, curso blue.
  • Sem travessões (—) na copy. Usar vírgula/dois-pontos. Sem ranges com en-dash ("19h às 23h", não "19h–23h").
  • Fills planos, sem gradientes (compatibilidade de clientes de email).
  • Botões de estado único (sem animação swipe; isso é só web).
  • UTMs obrigatórios em todos os CTAs: utm_source=brevo&utm_medium=email&utm_campaign=<chave>.
  • 680px de largura, padding lateral 40px, classes mobile aplicadas.
  • Não modificar componentes bloqueados sem pedido explícito.

04Próximo passo (proposta)

Esta v1 é o catálogo + fontes canónicas. Para fechar o sistema, consolidar os snippets num único kit Brevo (um ficheiro por componente, com variáveis documentadas) e, idealmente, servi-lo pelo plugin como os docs internos — assim deixa de haver cópias espalhadas em _sort_/.
